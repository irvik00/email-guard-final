# Синтетические письма для локальной демонстрации

Все адреса и имена вымышлены; домены `.invalid` не предназначены для реальной доставки. Ссылки не открывать. Файлы показывают разные форматы и ограничения, а не гарантированные эталоны. Ответы определяются только реальными компонентами приложения; имена файлов в модель не передаются.

- demo_01: запрошенное уведомление на английском.
- demo_02: явно нежелательное массовое предложение на английском.
- demo_03: запрошенное уведомление на русском.
- demo_04: нежелательная рассылка на русском.
- demo_05: инертный HTML с несовпадением подписи ссылки и адреса, опасной схемой, отпиской и фиктивным вложением.
- demo_06: длинное синтетическое письмо для наблюдения фиксированного лимита Laya.

Фактические ответы сохраняются проверкой HTTP в `reports/app/verification_runs/`, без заранее заданных вердиктов.
