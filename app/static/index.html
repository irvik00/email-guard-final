Письмо отправляется на сервер этого сервиса и обрабатывается в памяти. Приложение не сохраняет письмо. Для публичного демо используйте вымышленные примеры без личных данных.

В CPU-демо работает baseline E0. Режимы с Laya доступны в отдельно подготовленном локальном запуске.
